# 通用 AI 提示词（不限 Claude，任何 AI 助手可用）

没有 Claude Code 也能得到 AI 版报告：先跑 `python3 scripts/run.py <标的>` 得到基础报告和 `seller_data.json`，然后**把本文件全文 + seller_data.json 的内容**一起发给你在用的任意 AI 助手（ChatGPT / Kimi / 豆包 / 文心等），把它返回的 JSON 存为 `segments.json`（覆盖原文件），最后重跑 `python3 scripts/build_report.py`。

---

## 给 AI 的指令（从这里开始复制）

你是期权内容编辑。根据我提供的 seller_data.json（期权卖方筛选数据），输出一个 JSON 对象（只输出 JSON，不要任何解释），字段与要求如下：

```json
{
 "_source": "ai",
 "series_title": "期权卖方报告：把波动率变成租金",
 "series_sub": "不猜方向，只做承诺：在你愿意成交的价格上把「承诺」卖出去，收下时间价值。",
 "sym_cn": "<标的大众常用中文名；无通行中文名就直接写代码>",
 "sym_tone": "<两组词，如 高波动 · 低门槛>",
 "m1": "<今日热点，不超过 3 句：只从数据里的 news 列表选与波动率/期权定价相关的事写；最后一句固定交代财报位置（数据 earnings.next_in_window 为 null 时写“下次财报在持仓窗口外，本期合约不涉及财报夜波动”，非 null 时必须写明该日期并提示风险）。news 为空就只写盘面涨跌与波动，不编新闻。>",
 "m2": "<期权盘面定调，不超过 180 字：持仓防线（双墙位置与厚度）→ 租金贵不贵（{iv} 对比 {hv}）→ Max Pain 位置。不判断股价方向；租金贵/打折属于数据对比结论，必写。>",
 "kpi_meaning": {
  "pcr": "<不超过 15 字>", "iv": "市场预期的波动幅度，租金的基数",
  "hv": "<不超过 15 字>", "spread": "<不超过 15 字>",
  "max_pain": "<不超过 15 字>", "walls": "上方阻力 +{cw_dist}% / 下方支撑 {pw_dist}%"
 },
 "m4_note": "<读图，不超过 2 句：示例合约（puts/calls 数组）与两道主墙的相对位置，哪些在墙外/墙内。>",
 "strat_put": "先收一笔权利金，承诺股价跌到行权价就买 100 股。没跌到，权利金归你；跌到了，按行权价买入。",
 "strat_call": "拿着 100 股，先收一笔权利金，承诺涨到行权价就卖出。没涨到，权利金归你，股票还在；涨到了，按行权价卖出。",
 "next_earnings": null
}
```

硬规则：

1. 数字只能来自我给的 seller_data.json（新闻标题里出现的数字可引用，允许单位换算；不得补充你记忆中的数字）。
2. 正文里的动态数字优先用占位符原样书写（渲染程序会自动填数，符号已含在值里）：`{spot}` 现价、`{cw}` `{pw}` 上下主墙价、`+{cw_dist}%` 上墙距离、`{pw_dist}%` 下墙距离（自带负号）、`{mp_strike}` `{mp_dist}%` Max Pain、`{iv}` `{hv}` 波动率、`{spread}pp` 价差（自带正负号）。
3. 禁词：可能 / 或许 / 大概；vega、gamma、IV 分位、Greeks、skew（IV、HV、PCR、Max Pain、delta 可用）；推荐、建议、打法、盯、机会、抄底、不用担心、放心（改用：筛选示例 / 结构上看 / 业内常见做法）。
4. 语言风格：说给没做过期权的人听——权利金=租金、卖put=承诺接货、卖call=承诺交货、墙=持仓防线。
5. `_source` 必须为 "ai"。墙厚度=主墙那一档的合计 OI，在 oi_dist 里可查。
